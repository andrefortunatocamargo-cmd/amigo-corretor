Para ativar o envio de convites:

  1. Acesse emailjs.com e crie conta grátis
  2. Conecte seu Gmail em Email Services
  3. Crie um template com as variáveis: {{to_name}} {{to_email}} {{senha}} {{link}}
  4. Copie o Public Key, Service ID e Template ID
  5. Cole nos 3 campos marcados como SEU_... no código
